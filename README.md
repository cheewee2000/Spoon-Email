# Spoon Email

A fast, keyboard-first Gmail client for macOS and iOS in the spirit of Superhuman.
Multiple Gmail accounts, one unified inbox. No calendar, no AI.

**Version 0.13.3**

![Spoon Email screenshot](Screenshot%202026-08-12%20at%208.10.49%20AM.png)

## Features

- Multiple Gmail accounts → unified inbox, with a multi-column board view
- Keyboard-first triage: `j`/`k`, `e` archive, `r` reply, `c` compose, `⌘K` command palette
- Split inbox tabs (Important / Newsletters / Updates / Other) via Gmail categories
- Send later + undo send
- Instant local full-text search (FTS5) with Gmail server-search fallback
- One-click unsubscribe, block sender/domain, collapse quoted trails
- Optimistic local actions — UI never waits on the network
- Your mail stays between your Mac and Google: no third-party server, no telemetry

## Getting started

Spoon Email talks to the Gmail API with **your own** free Google OAuth client, so
your mail never flows through anyone else's infrastructure. The first time you
click **Add Account**, Spoon Email walks you through the one-time setup (~5 min):

1. Go to [console.cloud.google.com](https://console.cloud.google.com) → create a
   new project (any name, e.g. `spoon`).
2. **APIs & Services → Library** → search "Gmail API" → **Enable**.
3. **APIs & Services → OAuth consent screen** → External → fill in the app name
   and your email → **Audience: Testing** → add each Gmail address you'll connect
   as a **Test user**.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID** →
   Application type **iOS** → Bundle ID `com.cwandt.spoon` → Create.
5. Copy the **client ID** (looks like `1234-abc.apps.googleusercontent.com`) and
   paste it into the setup sheet in the app.

No verification review is needed while the OAuth client stays in Testing mode.

Scheduled sends fire while the app is running (on iOS: while the app is open —
if a scheduled time passes while the app is closed, the send happens the next
time you open it).

## Keyboard shortcuts (macOS)

`j`/`k` next/prev · `e` archive · `r` reply · `a` reply all · `f` forward ·
`u` read/unread · `s` star · `c` compose · `⌘K` command palette · `⌘N` new
message · `⌘R` sync · `⌘Z` undo send (while the toast shows)

## Building

```sh
brew install xcodegen   # once
xcodegen generate
open "Spoon Email.xcodeproj"
```

Or from the CLI:

```sh
xcodebuild -project "Spoon Email.xcodeproj" -scheme "Spoon Email" \
  -destination 'platform=macOS' build
```

## Architecture

- `MailCore/` — Swift package: Gmail REST client, OAuth 2 + PKCE (no Google SDK),
  GRDB/SQLite storage with FTS5, sync engine (history API + pending-op replay),
  outbox scheduler.
- `App/` — SwiftUI, one multiplatform target (macOS 15+, iOS 18+).
- Project file is generated by XcodeGen from `project.yml` (the `.xcodeproj` is
  not checked in).
